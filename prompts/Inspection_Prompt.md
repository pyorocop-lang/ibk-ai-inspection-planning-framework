# 검사기획 추천 프롬프트 (Inspection Prompt)

> **공통 원칙:** AI는 검사부문을 결정하지 않고 **근거와 함께 추천**만 하며, 최종 결정은 **검사협의회(Inspection Committee)** 가 수행한다.

## 1. Purpose (목적)
검사부문 후보의 위험을 분석하여 설명가능한 추천을 생성하는 프롬프트.

## 2. Scope (범위)
유니버스·신호 입력 → 추천 랭킹 출력.

## 3. Input (입력)
검사 유니버스, 위험 신호, 가중치.

## 4. Process (처리)
방법론(METHOD)에 따라 매핑·스코어링·랭킹·설명·반론을 수행하도록 지시한다. '추천'만 생성하고 결정하지 않도록 제약한다.

## 5. Output (출력)
추천 랭킹과 설명 카드.

## 6. Explainability Requirement (설명가능성 요건)
산출물은 근거·신뢰도·반론을 포함하여 사람이 이해·검증·재현할 수 있어야 한다. 모든 핵심 주장에는 출처를 표기한다.

## 7. Human Review (사람의 검증)
산출물은 1차 검토자의 근거·편향 점검을 거치며, 최종 결정은 검사협의회가 수행한다.

## 8. Example (예시)
'다음 신호로 검사부문 후보를 점수·순위·근거·신뢰도·반론과 함께 추천하라. 결정하지 말라.'

## 9. File Owner (문서 소유자)
