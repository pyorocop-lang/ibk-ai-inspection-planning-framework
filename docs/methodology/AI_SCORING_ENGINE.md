# AI 스코어링 엔진 (AI Scoring Engine)

> **공통 원칙:** AI는 검사부문을 결정하지 않고 **근거와 함께 추천**만 하며, 최종 결정은 **검사협의회(Inspection Committee)** 가 수행한다.

## 1. Purpose (목적)
검사부문 후보의 위험을 정량 점수로 산출하는 산식과 가중치 체계를 정의한다.

## 2. Scope (범위)
차원 정의, 정규화, 가중치, 합산식, 재현성 보장.

## 3. Input (입력)
위험 신호, 차원별 측정값, 가중치(`models/scoring/`).

## 4. Process (처리)
차원별 점수 산출 후 가중 합산한다.

| 차원 | 측정 | 가중치(예) |
|------|------|-----------|
| Likelihood | 발생 가능성 | 0.25 |
| Impact | 영향 | 0.25 |
| Velocity | 변화 속도 | 0.15 |
| Control Gap | 통제 취약 | 0.20 |
| Supervisory | 감독 관심 | 0.15 |

`총점 = Σ(차원점수 × 가중치)`. 가중치는 버전관리하며 변경 시 사유 기록.

## 5. Output (출력)
후보별 총점과 차원 분해표(점수 산출 근거).

## 6. Explainability Requirement (설명가능성 요건)
산출물은 근거·신뢰도·반론을 포함하여 사람이 이해·검증·재현할 수 있어야 한다. 모든 핵심 주장에는 출처를 표기한다.

## 7. Human Review (사람의 검증)
산출물은 1차 검토자의 근거·편향 점검을 거치며, 최종 결정은 검사협의회가 수행한다.

## 8. Example (예시)
여신 사후관리: 0.8·0.25 + 0.7·0.25 + ... = 8.4 (中 신뢰도).

## 9. File Owner (문서 소유자)
검사기획 AI 운영 담당 (Inspection Planning AI Steward)
