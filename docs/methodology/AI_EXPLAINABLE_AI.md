# 설명가능 AI 방법론 (Explainable AI)

> **공통 원칙:** AI는 검사부문을 결정하지 않고 **근거와 함께 추천**만 하며, 최종 결정은 **검사협의회(Inspection Committee)** 가 수행한다.

## 1. Purpose (목적)
AI 추천이 사람에게 이해·검증·재현 가능하도록 하는 설명가능성 요건을 정의한다.

## 2. Scope (범위)
근거 추적, 점수 분해, 신뢰도·반론 표기, 재현성.

## 3. Input (입력)
추론 로그, 점수 분해, 근거 출처.

## 4. Process (처리)
모든 추천에 대해 근거→차원→가중치→점수의 추적 경로와 반론·신뢰도를 제시한다. 동일 입력 → 동일 출력을 보장한다.

## 5. Output (출력)
설명 카드(근거·분해·신뢰도·반론)와 재현 가능한 산출.

## 6. Explainability Requirement (설명가능성 요건)
산출물은 근거·신뢰도·반론을 포함하여 사람이 이해·검증·재현할 수 있어야 한다. 모든 핵심 주장에는 출처를 표기한다.

## 7. Human Review (사람의 검증)
산출물은 1차 검토자의 근거·편향 점검을 거치며, 최종 결정은 검사협의회가 수행한다.

## 8. Example (예시)
'점수 8.4 = 민원(근거2)·규정변경(근거1)·검사경과(근거2) 가중합, 반론: 사고금액↓'.

## 9. File Owner (문서 소유자)
검사기획 AI 운영 담당 (Inspection Planning AI Steward)
