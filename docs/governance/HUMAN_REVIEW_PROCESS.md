# 사람 검증 프로세스 (Human Review Process)

> **공통 원칙:** AI는 검사부문을 결정하지 않고 **근거와 함께 추천**만 하며, 최종 결정은 **검사협의회(Inspection Committee)** 가 수행한다.

## 1. Purpose (목적)
AI 추천에 대한 1차 검토자와 협의회의 단계별 검증 절차를 정의한다.

## 2. Scope (범위)
추천 수령부터 결정까지의 사람 개입 절차.

## 3. Input (입력)
AI 추천 산출물.

## 4. Process (처리)
1차 검토(근거·환각·편향 점검) → 협의회 심의 → 결정 → 기록.

```mermaid
flowchart LR
    IN[AI 추천] --> R1[1차 검토자<br/>근거·신뢰도 검증]
    R1 --> R2[검사협의회<br/>심의·의결]
    R2 --> OUT[결정·기록]
```

## 5. Output (출력)
검증 의견과 최종 결정.

## 6. Explainability Requirement (설명가능성 요건)
산출물은 근거·신뢰도·반론을 포함하여 사람이 이해·검증·재현할 수 있어야 한다. 모든 핵심 주장에는 출처를 표기한다.

## 7. Human Review (사람의 검증)
산출물은 1차 검토자의 근거·편향 점검을 거치며, 최종 결정은 검사협의회가 수행한다.

## 8. Example (예시)
검토자가 근거2 출처 누락 발견 → 보완 요청 → 협의회 심의 재개.

## 9. File Owner (문서 소유자)
검사기획 AI 운영 담당 (Inspection Planning AI Steward)
