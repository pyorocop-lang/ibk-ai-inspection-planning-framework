# 참조 자료 (References)

본 디렉터리는 AI 검사기획 Framework가 참조하는 **외부·내부 기준 자료**를 보관한다.

> **공통 원칙:** AI는 검사부문을 결정하지 않고 **근거와 함께 추천**만 하며, 최종 결정은 **검사협의회**가 수행한다.

## 참조 범주
| 범주 | 예시 |
|------|------|
| 법령·감독규정 | 은행법, 감독규정, 시행세칙 |
| 검사 기준 | 검사 매뉴얼, 점검 표준 |
| 리스크 기준 | 리스크 분류·평가 기준 |
| AI 거버넌스 | 설명가능 AI·AI 윤리 가이드 |
