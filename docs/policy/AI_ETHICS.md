# AI 윤리 (AI Ethics)

> **공통 원칙:** AI는 검사부문을 결정하지 않고 **근거와 함께 추천**만 하며, 최종 결정은 **검사협의회(Inspection Committee)** 가 수행한다.

## 1. Purpose (목적)
공정성·투명성·책임성·개인정보 보호 등 AI 윤리 기준을 정의한다.

## 2. Scope (범위)
추론·산출·운영 전반의 윤리 준칙.

## 3. Input (입력)
정책·헌장, 관련 법규·내규.

## 4. Process (처리)
공정성(편향 배제)·투명성(과정 공개)·책임성(사람 책임)·비밀유지(검사정보 보호)를 준수한다. 위반 소지 발견 시 즉시 사람에게 보고한다.

## 5. Output (출력)
윤리 점검 결과와 위반 시 보고 절차.

## 6. Explainability Requirement (설명가능성 요건)
산출물은 근거·신뢰도·반론을 포함하여 사람이 이해·검증·재현할 수 있어야 한다. 모든 핵심 주장에는 출처를 표기한다.

## 7. Human Review (사람의 검증)
산출물은 1차 검토자의 근거·편향 점검을 거치며, 최종 결정은 검사협의회가 수행한다.

## 8. Example (예시)
특정 부서에 불리한 데이터 편중 발견 → 보정 후 사유 기록.

## 9. File Owner (문서 소유자)
검사기획 AI 운영 담당 (Inspection Planning AI Steward)
