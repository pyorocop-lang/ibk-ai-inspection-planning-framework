# AI 출력 표준 (AI Output Standard)

> **공통 원칙:** AI는 검사부문을 결정하지 않고 **근거와 함께 추천**만 하며, 최종 결정은 **검사협의회(Inspection Committee)** 가 수행한다.

## 1. Purpose (목적)
AI 산출물의 형식·표현·필수 항목을 표준화한다.

## 2. Scope (범위)
추천 카드, 랭킹표, 보고서, 알림의 공통 출력 규격.

## 3. Input (입력)
추론·스코어링·랭킹 결과.

## 4. Process (처리)
모든 추천은 `부문/순위/점수/근거/신뢰도/반론/대안`을 포함한다. 표현은 '추천'으로 명시하며 '결정/확정' 표현을 금지한다. 근거에는 출처 ID를 단다.

## 5. Output (출력)
표준 형식의 추천 카드·랭킹표·보고서.

## 6. Explainability Requirement (설명가능성 요건)
산출물은 근거·신뢰도·반론을 포함하여 사람이 이해·검증·재현할 수 있어야 한다. 모든 핵심 주장에는 출처를 표기한다.

## 7. Human Review (사람의 검증)
산출물은 1차 검토자의 근거·편향 점검을 거치며, 최종 결정은 검사협의회가 수행한다.

## 8. Example (예시)
'여신 사후관리 — 1위 — 8.4 — [근거ID] — 신뢰도 中 — 반론… — 대안…'.

## 9. File Owner (문서 소유자)
검사기획 AI 운영 담당 (Inspection Planning AI Steward)
