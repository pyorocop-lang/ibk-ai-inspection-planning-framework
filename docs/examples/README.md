# 예시 모음 (Examples)

본 디렉터리는 AI 검사기획 산출물의 **예시**를 보관한다(추천 카드·랭킹표·스코어카드·협의회 자료 등).

> **공통 원칙:** AI는 검사부문을 결정하지 않고 **근거와 함께 추천**만 하며, 최종 결정은 **검사협의회**가 수행한다.

## 수록 예정 예시
| 구분 | 내용 |
|------|------|
| 추천 랭킹표 | 부문·점수·근거·신뢰도·반론 |
| 스코어카드 | 차원별 점수 분해 |
| 협의회 자료 | 안건·추천 요약·의결란 |
| Decision Log | 추천 대비 결정·사유 |

## File Owner
검사기획 AI 운영 담당 (Inspection Planning AI Steward)
