# AI 아키텍처 (AI Architecture)

> **공통 원칙:** AI는 검사부문을 결정하지 않고 **근거와 함께 추천**만 하며, 최종 결정은 **검사협의회(Inspection Committee)** 가 수행한다.

## 1. Purpose (목적)
추론·스코어링·랭킹·학습 모델의 구성과 상호작용을 정의한다.

## 2. Scope (범위)
`models/` 하위 AI 컴포넌트의 역할·입출력·연계.

## 3. Input (입력)
정규화 데이터, 지식 그래프, 가중치·모델 정의.

## 4. Process (처리)
추론 → 스코어링 → 랭킹 → (환류)학습의 모델 파이프라인.

| 컴포넌트 | 역할 |
|----------|------|
| Reasoning | 위험 해석·근본원인·반론 |
| Scoring | 차원별 정량 점수화 |
| Ranking | 우선순위 산출 |
| Learning | 결과 피드백 반영 |

## 5. Output (출력)
설명가능한 추천(점수·순위·근거·신뢰도)과 모델 메타데이터.

## 6. Explainability Requirement (설명가능성 요건)
산출물은 근거·신뢰도·반론을 포함하여 사람이 이해·검증·재현할 수 있어야 한다. 모든 핵심 주장에는 출처를 표기한다.

## 7. Human Review (사람의 검증)
산출물은 1차 검토자의 근거·편향 점검을 거치며, 최종 결정은 검사협의회가 수행한다.

## 8. Example (예시)
Reasoning이 근본원인 도출 → Scoring이 점수화 → Ranking이 순위 → 추천 출력.

## 9. File Owner (문서 소유자)
검사기획 AI 운영 담당 (Inspection Planning AI Steward)
